\begin{abstractCN}
   本文受核桃外壳天然纹理启发，提出一种融合仿生学原理、计算建模、机器学习与智能优化的高性能抗冲击薄壳纹理设计方法。首先，基于图灵斑纹方程生成仿核桃表面特征的随机纹理，通过截面形态表征与起皱机理分析，结合碰撞仿真揭示纹理几何特征对防护性能的影响机制。据此，构建可参数化随机生成的类核桃防护纹理薄壳模型：以规整平面网格为基底，通过纹理特征映射生成三维形貌。对薄壳模型进行撞击模拟，建立面外位移场的响应样本库。针对撞击响应场计算效率瓶颈，提出Mechanics-enhanced图神经网络（GNN）框架。该模型通过学习薄壳几何拓扑与撞击载荷间的隐式物理映射，实现全场变形响应的实时高精度预测。基于上述预测模型，构建进化算法协同的优化设计框架，逆向求解最优纹理空间分布。本研究为仿生抗冲击薄壳结构的高效智能设计提供了新范式。

    \keywordsCN 图神经网络；进化优化；图灵纹理；抗冲击
\end{abstractCN}

\begin{abstractENG}
    Inspired by the natural textures of walnut shells, this study proposes a high-performance impact-resistant thin-shell texture design method that integrates bionic principles, computational modeling, machine learning, and intelligent optimization. First, random textures mimicking walnut surface features are generated based on Turing's reaction-diffusion equations. Through cross-sectional morphology characterization and wrinkle mechanism analysis, coupled with collision simulations, the influence of texture geometric features on protective performance is elucidated. Accordingly, a parametrically generative walnut-like protective texture thin-shell model is constructed: starting from a regular planar grid base, three-dimensional morphology is generated via texture feature mapping. Impact simulations on the thin-shell model establish a response database for out-of-plane displacement fields. To address computational efficiency bottlenecks in impact response fields, a Mechanics-enhanced Graph Neural Network (GNN) framework is proposed. This model achieves real-time high-precision prediction of full-field deformation responses by learning the implicit physical mapping between thin-shell geometric topology and impact loads. Based on the predictive model, an optimization design framework incorporating evolutionary algorithms is established to inversely solve the optimal texture spatial distribution. This research provides a novel paradigm for the efficient intelligent design of bionic impact-resistant thin-shell structures.

    \keywordsENG Graph neural network；sep Evolutionary optimization；sep Turing textures；sep Impact-resistant
\end{abstractENG}
